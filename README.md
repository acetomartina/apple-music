# Music UI 🎧

Un'interfaccia musicale responsive ispirata alle app di streaming, sviluppata con **React e TypeScript**.

## Funzionalità

- Ricerca di artisti e brani tramite l'API Deezer usata dal progetto.
- Schede dei brani e pagina di dettaglio.
- Selezione del brano e riproduzione dell'anteprima audio, quando disponibile.
- Navigazione con React Router e layout adattato agli schermi piccoli.

## Stack

React 19 · TypeScript · Vite · React Router · React Bootstrap · React Icons

## Avvio locale

```bash
npm install
npm run dev
```

Apri l'indirizzo mostrato da Vite nel terminale. La ricerca richiede una connessione a Internet e dipende dalla disponibilità dell'API esterna; le anteprime audio sono disponibili solo per i brani che le forniscono.

```bash
npm run build
npm run lint
```

> Progetto di studio frontend, non affiliato ad Apple Music o Deezer.
